# Open Sites

Тестовый сайт на GitHub Pages.

Адрес сайта: https://s35561821-rgb.github.io/Open-Sites/

Pages публикует содержимое ветки `main` из корня репозитория. Обычная статика без сборки: `index.html`, `styles.css`, `script.js`, `404.html`. Файл `.nojekyll` отключает обработку Jekyll.

Страница проверяет, что загрузились HTML, CSS и JavaScript, а ссылка на несуществующую страницу показывает собственную страницу 404.
